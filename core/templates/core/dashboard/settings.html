Administrator workflow

Enroll a Gmail mailbox

  1. Create a pending mailbox for this organization in Django admin.
  2. Configure the separate read-only Workspace delegation identity.
  3. Run the enrollment command for the exact organization and mailbox. Initial synchronization starts on the next poll.
python manage.py enroll_gmail_mailbox --organization {{ organization.slug }} --mailbox ADDRESS

The application mailbox allowlist does not narrow the underlying Workspace domain-wide delegation grant. No Gmail tokens or keys are shown here. A Gmail connection is not created by dashboard sign-in.
